Welcome to the Mushroom Classification application! This web app is designed to help you identify different types of mushrooms based on their characteristics.

Using a machine learning model trained on various mushroom features, you can input specific attributes such as odor, gill color, spore print color, gill size, and bruises to predict whether a mushroom is edible or poisonous.
